# 东华大学一站式学生服务大厅网站 · 数据维护说明

本网站内容全部由 `data/` 目录下的 JSON 文件驱动，**修改数据文件即可更新网站，无需改动任何页面代码**。

## 如何更新（两步）

1. 在 GitHub 网页端打开 `data/` 下对应 JSON 文件，点击铅笔图标（编辑按钮）；
2. 修改内容后点击 **Commit changes**（提交更改）即可。

网站会在几分钟内自动更新（GitHub Pages CDN 缓存，最多等待数分钟，可 Ctrl+F5 强刷查看）。

> 提示：JSON 格式对符号严格，字符串必须用英文双引号 `"` 包裹；**不要删掉逗号、引号、括号**；每新增一条数据记得在上一条末尾补逗号。改完后如果页面空白或显示异常，多半是 JSON 语法出了问题，可对照示例检查。

## 各文件说明

### 1. `settings.json` — 站点全局信息

| 字段 | 含义 | 如何填 |
|---|---|---|
| `siteName` / `shortName` / `slogan` | 站点名称与口号 | 一般不用改 |
| `address` / `hours` / `email` | 地址、工作时间、邮箱 | 有变动时修改 |
| `officialAccount` | 微信公众号名称 | 填公众号名称（如\"东华大学一站式学生服务大厅\"），将展示在页脚与关于页 |
| `qrcode` | 公众号二维码图片路径 | 把二维码图片放入 `assets/img/`，填 `assets/img/xxx.jpg` |
| `videoUrl` | 宣传视频 | 把视频放入 `assets/video/`，填 `assets/video/xxx.mp4`；或用外部视频链接 |
| `videoPoster` | 视频封面图 | 填图片路径，不填则显示视频第一帧 |
| `banners` | 首页轮播图 | 格式见下，把图片放入 `assets/img/` 后填写路径 |
| `links` | 常用链接（页脚/关于页展示） | 每条含 `name`（名称）与 `url`（网址） |

轮播图示例（首页上半部分自动滚动，每张可带跳转链接）：
```json
"banners": [
  {"img": "assets/img/banner-1.jpg", "title": "2026年秋季招新推文", "link": "https://mp.weixin.qq.com/s/xxxx"},
  {"img": "assets/img/banner-2.jpg", "title": "爱心捐赠活动回顾", "link": ""}
]
```
- `img`：图片路径（放入 `assets/img/` 后填写）；
- `title`：图片下方显示的标题文字，可留空；
- `link`：点击图片跳转的网址（公众号文章、活动页等）；不需要跳转时留 `""`。

### 2. `counters.json` — 五个柜台的业务信息

- `counters` 数组按顺序放五个柜台，每个含 `id`、`name`、`dept`、`intro`（柜台简介）与 `services`（业务列表）；
- 每条业务含 `name`（业务名）、`desc`（一句话说明）与 `tips`（注意事项，一条一条列，可为空数组 `[]`）。

### 3. `notices.json` — 通知公告（首页置顶 + 通知公告页）

每条通知格式：
```json
{
  "id": 3,
  "title": "国庆假期暂停值班通知",
  "date": "2026-10-01",
  "tag": "重要",
  "link": "https://mp.weixin.qq.com/s/xxxx",
  "linkText": "查看公众号原文",
  "body": "国庆假期（10月1日至7日）大厅暂停值班，10月8日起恢复正常。"
}
```

- `tag`：`"重要"` 的通知会置顶显示在首页；其他值（如 `"通知"`）仅出现在通知公告页；
- `link` / `linkText`：需要跳转公众号文章或网页时填写，填了会在通知条上显示\"查看原文\"链接；不需要跳转时留 `""`。

### 4. `schedule.json` — 值班安排与空班情况（常驻展示）

- `hours`：常规值班时间文案（如 `"周一至周五 10:00-19:00（法定节假日除外）"`），有变动时同步修改；
- `shifts`：一天内的班次数组（如 `["10:00-12:20", "12:20-14:40", "14:40-17:00", "17:00-19:00"]`），每班 2 小时 20 分钟、最后一班 2 小时；
- `shiftNote`：班次的补充说明文字；
- `weekly`：周一至周日各天的常规状态（值班 / 休息），对应英文缩写 `mon`~`sun`；
- `counterNames`：五个柜台的展示名称（`c1`~`c5`），空班提示时按此显示；
- `exceptions`：**临时变更（空班、暂停）都在这里加**，格式：
```json
{
  "date": "2026-11-05",
  "type": "空班",
  "shift": "14:40-17:00",
  "counters": ["c2", "c3"],
  "note": "柜台二、柜台三因内部培训下午暂停服务"
}
```

| 字段 | 含义 |
|---|---|
| `date` | 变更日期，格式 `2026-11-05` |
| `type` | `"空班"`（部分柜台不值班）或 `"暂停"`（全体暂停） |
| `shift` | 空班发生在哪个班次（填班次时间，如 `"14:40-17:00"`）；**不填或填 `"全天"` 表示该柜台当天空班一整天** |
| `counters` | 空班的柜台 id（`c1`~`c5`）；`type` 为 `暂停` 时可不填或留空数组 |
| `note` | 给同学看的说明，如"内部培训""临时会议" |

值班安排页把本周（周一至周五）的空班情况按班次整理成一张表：左侧是四个班次时间（10:00-12:20 / 12:20-14:40 / 14:40-17:00 / 17:00-19:00），上侧是周一至周五，**有空的格子标出空班柜台，空白即该时段正常值班**；`exceptions` 的历史记录同步显示在下方时间线上，首页状态横幅同步高亮。
> 约定：值班/空班变更请**提前至少一天**更新 `exceptions`，避免同学跑空。

### 5. 宣传素材（图片/视频）

- 图片：放入 `assets/img/`，在 `settings.json` 的 `banners` 中登记（首页轮播）或直接在页面代码中引用；
- 视频：放入 `assets/video/`，在 `settings.json` 的 `videoUrl` 中登记（首页与关于页展示）。

## 新建、删除课程/柜台等结构调整

页面骨架（导航、柜台列表、值班页、通知页、关于页）在 `index.html`、`counters.html`、`counter1.html`~`counter5.html`、`schedule.html`、`notices.html`、`about.html` 中。数据结构不变时无需改动这些文件；如需要大结构调整，请咨询站点维护人员。
